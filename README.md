# privacy-policy

<h2>Hesap Silme</h2>
<p>Uygulamada hesabınızı kalıcı olarak silebilirsiniz:</p>
<ol>
  <li>Uygulamayı açın ve giriş yapın</li>
  <li>Sağ üst köşedeki ⋮ menüsüne tıklayın</li>
  <li>"Hesabı Sil" seçeneğini seçin</li>
  <li>Onay ekranında "Hesabı Sil" butonuna basın</li>
</ol>
<p>Hesabınız ve tüm verileriniz kalıcı olarak silinecektir.</p>
