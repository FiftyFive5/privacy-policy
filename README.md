# Taksi Kasa — Gizlilik Politikası

Taksi Kasa (com.vardiyatakip.mobile) uygulamasının gizlilik politikası.
Geliştirici: Hüseyin Arda Ellibes

Yayın adresi: https://fiftyfive5.github.io/privacy-policy/

<h2>Hesap Silme</h2>
<p>Uygulamada hesabınızı kalıcı olarak silebilirsiniz:</p>
<ol>
  <li>Taksi Kasa uygulamasını açın ve giriş yapın</li>
  <li>Sağ üst köşedeki ⋮ menüsüne dokunun</li>
  <li>"Hesabı Sil" seçeneğini seçin</li>
  <li>Şifrenizi girip "Hesabı Sil" butonuna basın</li>
</ol>
<p>Ayrıntılar: https://fiftyfive5.github.io/privacy-policy/#hesap-silme</p>
